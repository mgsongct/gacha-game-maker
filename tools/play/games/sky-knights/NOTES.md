# sky-knights — 생성 기록 메모

- 입력: `input.json` (자율 모드, 대원 6명). 글 AI 역할: Claude 에이전트(앱이 보낸 프롬프트만 보고 답함, 앱 소스 미열람). 2장 기억 정리 1/4 조각만 점검자가 답함.
- 단계: `game-after-new.json`(재생, 호출 5회 — 루시안의 인라인 스킬이 검증에 걸려 스킬 설계 1회) → `game-after-skills.json`(대상 없음) → `game-after-chapter.json` = `game.json`(2장 「검은 돛의 그림자」, 새 대원 마테오·아델).
- 초기 하네스 오류의 흔적: `responses/skill-(카시아·브람·넬·이브·비비안)-*`는 멀쩡한 인라인 스킬을 다시 설계하게 한 기록(지금은 임시·기본 스킬인 대원만 대상). 요청 구분이 프롬프트 앞 400자 기준이라 2장 스테이지 대본이 한 요청으로 묶였던 문제는 kind를 전체 해시로 바꾸고 `rekind.mjs`로 이름을 옮겨 해결, 2~4스테이지 대본을 따로 받음. `attempt-chapter.json`은 대본이 대기 중일 때 앱이 장면 구성안을 대본으로 넣고 장을 연 상태(QA 근거로 보존).
- 글 AI가 남긴 문제(요약): 공통 규칙의 속성 상성이 세계관에서 정한 순서와 다름("뇌전은 증기에 강함", "증기은") · 스킬 스키마 예시 모순 · 오프닝·1장에 원본 샘플 목록 · 표정 목록 없음 · 1장 요청에 프롤로그 대본 없음 · 처음 동료 "아는 사이" vs 오프닝 "첫 만남" · 2장이 1장에 나온 이브를 "아직 등장하지 않은 단원"으로(등장·보유가 플레이 진행 기준) · 비망록 내용 없이 "비망록 비밀을 엮어라" · 세력 우호 시점과 "반전" 요구 충돌 · 회담 스테이지에 "전투 전/후 대본" 요구, 회담 상대·주장·증거 정보 없음 · 2장 구성 3.1만 자에 새 대원 스킬 명세 전체.
