# idol-audition — 생성 기록 메모

- 입력: `input.json` (자율 모드, 대원 6명). 글 AI 역할: Claude 에이전트(앱이 보낸 프롬프트만 보고 답함, 앱 소스 미열람).
- `game.json` = `game-after-new.json`: `node tools/play/generate.mjs … new`로 응답을 **재생**해 만든, 앱이 실제로 저장하는 상태. 6명 모두 대원 생성 단계의 인라인 스킬이 앱 검증을 통과해 그대로 쓰임.
- `responses/skill-*`·`game-after-skills.json`: 초기 하네스의 `skills` 단계가 "설계 기록이 없는 대원"까지 대상으로 잡아(도구 오류, 지금은 임시·기본 스킬인 대원만) 멀쩡한 스킬을 다시 설계하게 한 기록. 이때 하네스가 일부러 낸 대기 응답(529)이 앱의 재요청 프롬프트에 "직전 실패를 수정하세요: …요청을 제한…" 문구로 들어간 것(`prompts/skill-*-2·-3`)은 앱의 실제 동작(서버 오류도 실패 원인으로 프롬프트에 넣음)이라 QA 발견으로 남김.
- 글 AI가 프롬프트를 읽으며 남긴 문제(요약): 전투 없는 장르인데 세계관 단계가 적대·몬스터 세력과 전투 메뉴를, 장 단계가 "마지막 스테이지는 반드시 전투·보스"와 적 수치를 강제 · 프롬프트의 배경·소품 목록에 원본 샘플 이름 · 공통 규칙의 속성 상성 설명 오류("청량은 열정에 강함", "우아은") · 스킬 스키마 예시 모순(`crit_up`이 효과 목록에 없음, 백분율인데 예시 1.8, `studio:true` 필수인데 예시에 없음) · 표정·fx 목록 미제공 · 줄 수 범위를 넘겨도 앱이 받아들임(답에서 직접 줄임).
