# 전투 개선 · 캐릭터 활용 콘텐츠 · 생성 연계

## 1. 현황 조사 (변경 전)

| 항목 | 상태 |
|---|---|
| 캐릭터를 쓰는 곳 | 메인·이벤트 스테이지, 훈련(재료), 주간 레이드, 미지 탐사(카드 로그라이크), 연습장, 파견(원정 모드). 파견을 빼면 **전부 같은 자동 전투**이고, 전투 밖에서 캐릭터를 쓰는 곳은 로비 터치·선물·톡 정도 |
| 스테이지 | 모두 "적 전멸" 하나. 스테이지마다 다른 조건이 없어 **편성 = 전투력 높은 4명**으로 끝남. 별 조건도 모든 스테이지가 같음(전원 생존·71초) |
| 전투 중 조작 | 필살기 타이밍과 속도뿐. 누구를 먼저 칠지 정할 수 없음 |
| 모을 이유 | 속성 상성 말고는 소속·역할·속성별로 캐릭터를 여럿 키울 이유가 약함 |
| 생성 | 새 장 생성은 적 이름·속성·보스 여부만 정함. 전장의 특색은 대본에만 있고 전투에는 반영되지 않음 |
| 실제 플레이 확인 | 샘플 1-1을 Lv.1 4명으로 돌려 보니 9초에 지원형이 쓰러짐(적 필살기). 첫 스테이지 난이도는 따로 볼 필요가 있음(이번 범위 밖) |

## 2. 장르 조사

| 사례(공통 패턴) | 요점 | 이 앱에 맞춘 것 |
|---|---|---|
| 스테이지 기믹·환경 효과(명일방주 지형·특수 규칙, 블루 아카이브 시가지·야외·실내 지형 상성) | 같은 적이라도 스테이지마다 다른 편성을 요구 | **전장 규칙** |
| 스테이지별 별 조건(여러 가챠 RPG의 "○○ 속성 2명 이상" 미션) | 클리어한 스테이지를 다른 편성으로 다시 하게 만듦 | **별 조건** |
| 위기협약·고난도 계약(명일방주) | 불리한 조건을 고를수록 보상↑ | 확장 아이디어(탑에 위험도) |
| 소속·속성 제한 탑(니케 기업 타워, 여러 게임의 속성 탑) | 특정 소속·속성만 출전 → 수집 폭이 넓어짐 | **시련의 탑**(통합 + 제한 탑) |
| 일정·스케줄(블루 아카이브 스케줄) | 장소에 있는 캐릭터와 짧은 장면 + 인연 상승, 하루 횟수 제한 | **일정** |
| 집중 공격·타깃 지정(여러 오토 배틀 RPG) | 자동 전투에 한 가지 판단을 더함 | **집중 지시** |

특정 게임의 수치·이름은 쓰지 않고 공통 구조만 가져왔습니다.

## 3. 이 앱의 결정

### 전장 규칙·별 조건 (`src/main/0485-battle-rules.js`)
| 규칙 | 효과 |
|---|---|
| 속성 공명 / 속성 억제 | 그 속성 유닛(양쪽) 공격 +30% / −25% |
| 역할 우대 | 그 역할 아군 공격·방어 +25% |
| 홈그라운드 | 그 소속 아군 체력·공격 +25% (2명 이상인 소속만) |
| 철갑 전선 | 적 방어 +60%, 체력 −15% |
| 요새 | 적 체력 +40%, 공격 −15% |
| 질풍 | 모두 속도 +20% |
| 광란 | 모두 공격 +35% |
| 시간 제한 | n초(20~119) 안에 못 이기면 실패 |

- 별 조건(세 번째 별): n초 안에 승리 / 남은 체력 n% 이상 / ○속성·○역할·○소속 2명 이상 / ○역할 없이 / n명 이하. 없으면 예전처럼 71초
- 편성 화면에 전장 규칙과 별 조건이 나오고, 결과 화면에서 달성 여부를 보여 줌
- 규칙은 엔진에 들어가기 전에 능력치로 반영(`fieldApply`)하고, 시간 제한은 엔진 `maxTime`. 엔진 코드는 바꾸지 않음

### 집중 지시
- 전투 중 적을 누르면 8초 동안 엔진의 `focus` 상태가 걸려 아군 기본 공격이 그 적을 노림. 재사용 12초

### 시련의 탑 (`src/main/0125-tower.js`, 도전 화면)
- 통합 탑 + 소속별 탑(2명 이상인 소속) + 속성별 탑. 제한 탑은 편성 목록과 출전을 그 조건으로 제한함
- 층 n: 적 2~4명, 5층마다 보스. 강해지는 정도는 메인 스토리 곡선 `enemyTarget((n−1)×0.4)`. 같은 층은 늘 같은 구성
- 적은 이 게임 스토리에 나온 적을 다시 씀. 속성 탑에서는 그 속성이 유리한 적이 섞여 나옴
- 층마다 전장 규칙·별 조건(3층 중 2층에 규칙)
- 첫 돌파 보상: ◆20 + 골드, 5층마다 ◆80 + 골드 + 코어 2. 행동력은 쓰지 않음

### 일정 (`src/main/0135-schedule.js`, 로비 → 일정)
- 하루 3번. 장소마다 오늘 나와 있는 보유 캐릭터 2명(날짜로 정해짐). 좋아하는 것(개성 시트 likes·hobby)이 장소 이름·태그와 맞으면 ♥ 표시가 붙고 우선 등장
- 방문하면 장면(대본)을 보고 호감도 +20(좋아하는 장소 +30)과 골드를 받음. 같은 장소는 하루 한 번
- 장면은 AI가 만든 `c.spotTalk[장소]`를 쓰고, 없으면 개성 시트로 짧은 기본 장면을 만듦(선택지 포함)

### 생성·업데이트 연계
| 대상 | 새로 만들 때 | 예전 생성물 |
|---|---|---|
| 스테이지 규칙 | 장 생성 스키마에 `field`(AI가 이야기에 맞게 고름) → `buildStages`가 검증하고, 비면 `stageAutoRules`가 정함(첫 스테이지는 규칙 없음, 보스 스테이지는 시간·체력 목표) | 점검 `s_rules` → 자동 |
| 일정 장소 | 일정 화면에서 자료실 배경으로 자동 생성, 또는 AI(세계관 맞춤, 태그 포함) | 점검 `g_spots` → 자동 |
| 일정 장면 | 캐릭터마다 AI가 모든 장소의 장면을 한 번에 만듦 | 점검 `c_spot` → AI(`ai-run` 모드) |
| 탑 | 생성할 것 없음(스토리 적·소속·속성에서 만들어짐) | — |

생성 규칙 버전은 5입니다.

## 4. 확장 아이디어
- 탑 위험도(위기협약식): 불리한 규칙을 골라 더하면 보상↑
- 웨이브 전투(엔진에 적 교체 단계 추가 필요)
- 일정 장소 레벨·장소별 선물, 두 사람이 함께 나오는 장면
- 전장 규칙을 이벤트 스토리와 레이드에도 적용
- 첫 스테이지 난이도 점검(지원형이 먼저 쓰러지는 문제)

## 5. 출처
- 명일방주 위기협약·스테이지 특수 효과, 블루 아카이브 지형 상성·스케줄, 니케 트라이브 타워 — 각 게임 위키의 공통 시스템 설명을 참고해 구조만 정리
