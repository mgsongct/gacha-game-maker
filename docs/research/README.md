## 노트 쓰는 법

각 노트는 다음 순서로 씁니다.

1. **조사**: 장르에서 흔한 방식과 출처. 특정 게임을 그대로 옮기지 않고 공통 패턴만 정리합니다.
2. **이 앱의 결정**: 무엇을 채택하고 무엇을 뺐는지, 그 이유
3. **수치·공식**: 기본값과 계산식. 바꾸면 어떤 결과가 나오는지 예시 표
4. **확장 아이디어**: 아직 구현하지 않은 것과 넣을 때의 위치
5. **출처**

## 새 조사 추가

`docs/research/<주제>.md`를 만들고 위 표에 한 줄을 추가합니다.
