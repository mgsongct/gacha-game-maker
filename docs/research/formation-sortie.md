# 대열(근접·원거리·지원) · 출격 경로 · 일러스트만으로 되는 전투 체계

## 1. 현황 조사 (변경 전)

| 항목 | 상태 |
|---|---|
| 캐릭터 포맷 | `role`(atk·def·sup), `pos`(포지션 id, 기능 보정만), `elem`, `faction`, `weapon`. **사거리 항목이 없음**. 근접·원거리는 엔진 `isRanged`가 무기·설명 글자("총·활·마법…")로 짐작해 **연출(돌진 vs 투사체)에만** 씀 |
| 대열 | 편성 화면에 전열(1·2)·후열(3·4) 표시가 있지만, 엔진에서는 "전열이 노려질 확률 2배"뿐. 후열 보호·엄호·자리 상성이 없어 **모두 일렬로 서서 같은 규칙으로 맞고 때림** |
| 포지션 | 게임 규칙의 포지션(선봉·방벽·사수·의무…)은 능력치 %만 바꿈. 자리·사거리와 연결되지 않음 |
| 스테이지 흐름 | 스테이지 = 전투 1번. 들어가 싸우면 끝. 진격/퇴각 판단, 갈림길, 연전으로 깎이는 체력이 없음 |

## 2. 조사: 별도 모델링 없이 캐릭터 일러스트만으로 되는 전투·시스템

3D 모델·스파인·도트 애니메이션 없이 **일러스트(스탠딩·카드) 몇 장으로 돌아가는 구조**를 찾았습니다. 이 앱은 AI로 그린 정지 그림만 있으니 이 조건이 핵심입니다.

| 유형 | 사례(공통 패턴) | 일러스트만으로 되는 이유 | 이 앱 반영 |
|---|---|---|---|
| 해역 출격형 | 칸코레식 출격: 지도 위 지점을 진행하며 지점마다 자동 전투, 이긴 뒤 **진격/퇴각**, 함종·편성에 따라 **갈림길이 정해짐**, 대파 상태로 진격하면 위험 | 전투는 카드 컷·컷인·숫자만 보여 줌 | **출격 경로**(이번) |
| 지점 이동형 | 도검난무식: 지도 칸을 따라 진행, 편성(칼 종류)에 따라 지나갈 수 있는 길이 다름, 진형 선택 | 카드 일러스트 + 간단한 연출 | 갈림길 조건(지원형 필요) |
| 위치(랭크) 전투 | 다키스트 던전식: 4칸 대열, **스킬마다 쓸 수 있는 내 자리와 칠 수 있는 적 자리**가 정해짐, 밀치기·당기기로 자리 변화 | 캐릭터당 몇 장의 포즈 그림 | **대열**(전열·후열·사거리, 이번) / 스킬별 자리 조건(확장) |
| 카드 덱 전투 | 스파이어류: 손패·에너지·적 의도 표시 | 카드 일러스트만 | 이미 있음(미지 탐사) |
| 오토 배틀 카드 | 브라우저 가챠의 카드 진열 자동 전투: 카드가 앞으로 튀어나오며 공격, 피격 흔들림, 숫자, 컷인 | 정지 그림 + CSS 움직임 | 이미 있음(전투 v2 연출) |
| 텍스트 어드벤처 전투·선택 | 사건 지점의 선택지 → 성공·실패 | 배경 + 스탠딩 | 사건 지점(확장) |

**일러스트만 쓰는 연출 기법**: 카드 돌진·되튐, 피격 흔들림·붉은 번쩍임, 투사체 선, 스킬 컷인(띠 + 일러스트), 표정 바꾸기, 감정 아이콘, 화면 효과(연출 엔진 0462), 전열·후열 크기·높이 차이. 대부분 이미 앱에 있어서 **규칙(대열·경로)을 바꾸는 것이 연출보다 효과가 큼**.

## 3. 이 앱의 결정

### 대열 (엔진 `options.formation`, `src/modules/combat/030-core.js`, `src/main/0487-formation-sortie.js`)
| 규칙 | 내용 |
|---|---|
| 사거리 | 캐릭터 `c.range` = melee(근접)·ranged(원거리)·support(지원). 없으면 포지션의 사거리 → 역할(방어=근접, 지원=지원) → 무기·설명으로 추정 |
| 자리 | 아군: 편성 1·2 전열, 3·4 후열(2명 이하면 모두 전열). 적: 근접·보스 전열, 원거리·지원 후열(근접이 없으면 모두 전열) |
| 후열 보호 | **근접 공격은 전열이 살아 있으면 전열만** 노림. 전열이 무너지면 후열이 드러남 |
| 엄호 | 원거리 공격이 후열을 노리면 전열 방어형이 30% 확률로 대신 맞음("엄호") |
| 자리 상성 | 후열 근접 일반 공격 ×0.7, 후열 원거리 ×1.1, 전열의 원거리·지원이 받는 피해 ×1.25, 전열 방어형이 받는 피해 ×0.9, 후열 지원형 회복 ×1.2 |
| 화면 | 편성 칸에 사거리 아이콘(⚔ ➶ ✚)과 잘못된 배치 경고, 전투 카드에 사거리·전열/후열 표시 |

- 포지션 프리셋에 사거리를 붙임(선봉·근접·방벽=근접, 사수·술사=원거리, 의무·보조=지원…). 게임 규칙 편집에서 포지션마다 바꿀 수 있음
- 설정 → 게임 → 전투 체계에서 끄면 예전 방식(엔진은 옵션이 없으면 예전과 같음)

### 출격 경로
```
전초전(약한 적 2) ─┬─ 정면 돌파(강한 적 3, 전장 규칙, 보상↑) ─┬─ 보스(스테이지 원래 적)
                   └─ 우회로 보급(체력 30% 회복, 지원형 필요) ─┘
```
- 출격할 때 행동력 1번. 지점마다 **체력이 이어짐**(대파 25% 미만 경고, 쓰러지면 그 출격 동안 전투 불능)
- 지점을 이길 때마다 골드·경험치 + **진격 / 퇴각** 선택. 갈림길에서 길 선택(조건이 안 맞으면 잠김)
- 보스를 이기면 스테이지 클리어(첫 클리어 보상·별·다음 대본). 지면 출격 실패. 진행은 `P().sortie`에 저장돼 다시 열면 이어 감
- 지점 적은 스테이지 적(이미 밸런스된 값)을 줄여서 만듦 → 예전 스테이지도 그대로 경로가 생김

### 생성·업데이트 연계
| 대상 | 새로 만들 때 | 예전 것 |
|---|---|---|
| 사거리 | 캐릭터 스키마에 `range`(무기·전투 방식에 맞게) | 점검 `c_range` → 추정해서 자동 |
| 경로 이름 | 장 생성 스키마 `route`(첫 교전 지점·갈림길 상황·정면/우회 길·최종 지점 이름, 이야기와 맞게) | 이름이 없으면 기본 이름 |

생성 규칙 버전 7입니다.

## 4. 확장 아이디어
- 스킬별 자리 조건(이 자리에서만 쓸 수 있음·이 자리 적만 침)과 밀치기·당기기
- 갈림길 조건을 더 다양하게: 속도(빠른 편성), 정찰(지원형 수), 소속
- 지점 종류: 사건(선택지), 함정, 정찰, 야간전
- 경로를 장 단위로 잇기(장 지도), 해역 기믹(보스 체력 깎기 연속 출격)
- 대파 진격 패널티(쓰러지면 회복에 시간)
