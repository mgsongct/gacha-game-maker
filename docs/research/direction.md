# 캐릭터 커뮤 연출 · 연출 엔진 · 에셋 공유

## 1. 현황 조사 (변경 전)

| 항목 | 상태 |
|---|---|
| 대화 무대 | 말하는 한 사람만 화면에 나옴(`#vnChar` 하나). 두 사람이 주고받는 장면에서 상대가 사라짐 |
| 감정 표현 | 표정 그림(`이름[표정]`, 대사로 자동 고르기 `textFace`)뿐. 표정 그림이 없으면 감정이 전혀 안 보임 |
| 동작·효과 | `[효과: 흔들림|플래시|암전]` 세 가지(화면 전체). 캐릭터 동작(뛰어오름·떨림 등)과 지속 효과(비·회상 등)가 없음 |
| 메신저 | 글·사진만. 스티커 없음 |
| AI 생성 | 대본 형식 안내에 효과 세 가지만 있어 AI가 연출을 거의 쓰지 않음. 예전 대본에 연출을 더할 방법이 없음 |
| 에셋 | 자료실(`G.lib`)이 게임마다 따로 있음. 같은 배경을 게임마다 다시 그려야 하고, 게임 안 중복(같은 프롬프트)·안 쓰는 자료를 볼 곳이 없음. 별칭(alias)은 적 그림 재사용에만 쓰임 |

## 2. 장르 조사

| 사례(공통 패턴) | 요점 |
|---|---|
| 만화 기호(漫符): 하트·땀방울·분노 마크(💢)·느낌표·물음표·말줄임·음표·홍조 빗금·Zz | 표정 그림이 적어도 감정이 읽힘. 머리 옆에 짧게 떴다 사라짐 |
| 가챠 게임 커뮤(블루 아카이브 메모리·모모톡, 학원/아이돌 계열 커뮤): 2인 무대·화자 강조, 점프·흔들림 같은 짧은 몸짓, 감정 이모트 | 정지 그림 몇 장으로 생동감을 냄 |
| 비주얼 노벨: 화면 흔들림·섬광·암전·회상(세피아)·날씨 파티클·집중선 | 장면 분위기를 바꾸는 지속 효과는 "켜기/끄기" 쌍 |
| 메신저 스티커 | 짧은 감정 표현으로 톡 리듬을 만듦 |

특정 게임의 그림·연출 자산은 쓰지 않고, 이 앱용 기본 아이콘(SVG)을 새로 만들었습니다.

## 3. 이 앱의 결정

### 연출 엔진 (`src/main/0462-direction.js`, `style/0180-direction.css`)
| 문법 | 동작 |
|---|---|
| `이름[표정\|감정\|동작]: 대사` | 대괄호 안을 `\|`로 나눔. 순서 상관없이 감정 아이콘·동작·표정을 알아봄(기존 `이름[표정]`은 그대로) |
| `[연출: 이름 감정 동작]` | 대사 없이 감정·동작만 |
| `[효과: …]` | 흔들림·강한흔들림·플래시·붉은섬광·암전·페이드(한 번) / 집중선·비·눈·벚꽃·회상·비네트(`[효과: 비 끝]`까지 지속) |
| `[스티커: 감정]` | 메신저(톡·대본 속 톡)에 큰 감정 아이콘 |

- 감정 아이콘 13개: 하트·땀·화남·놀람·의문·침묵·음표·번뜩·눈물·홍조·졸림·반짝·한숨. 아이콘마다 등장 방식(튀어나옴·흘러내림·두근거림·갸웃·떠오름)이 다르고, 별칭(♥·💦·💢·!·?·당황·분노 등)도 받음
- 동작: 점프(뛰어오름)·흔들(도리도리)·떨림·끄덕·갸웃·다가옴·물러남·퇴장·등장·쓰러짐
- **두 사람 무대**: 최근 두 화자를 좌우로 세우고 말하는 사람을 밝게(설정 → 화면·연출 → 대화 무대)
- **자동 감정**(기본): 대본에 연출이 없는 줄은 대사로 감정을 고름(예: "?!" → 놀람, "좋아해" → 하트). 설정에서 "대본에 쓴 것만"·"끄기"
- 로비 터치에도 감정 아이콘이 뜸(머리 → 하트, 대사에 맞는 감정)
- 동작 줄이기(prefers-reduced-motion)면 움직임 애니메이션을 끔

### AI 연계
- 프롬프트 조각 `DIRECTION_GUIDE`(프롬프트 스튜디오에서 고칠 수 있음)가 대본 형식 `SCRIPT_FMT`에 들어가 모든 스토리·이벤트·메모리얼·일정 장면 생성에 쓰임. 메신저 형식에는 스티커 안내
- **AI 연출 입히기** `directScript`: 대사·나레이션·선택지는 그대로 두고 연출만 더함. 결과의 대사가 한 글자라도 다르면 버림(`dirStrip` 비교)
- 점검 규칙 `s_direct`: 연출이 없는 예전 스테이지 대본 → AI 연출 입히기(되돌리기 가능). 생성 규칙 버전 6

### 에셋 관리 (`src/main/0565-asset-library.js`, 설정 → 게임 → 에셋 관리)
- **공유 보관함**: 게임끼리 함께 쓰는 배경·소품·CG·적·아이콘·감정 아이콘·음악·효과음. 목록은 `ggm-shared-assets`, 파일은 IDB `shared::<id>`
- **자동 재사용**: 새 장 생성·대본 스캔으로 그림 없는 자료가 생길 때, 보관함에 같은 종류·이름이 있으면 바로 가져옴. AI 컨텍스트에 "공유 보관함 배경" 이름을 알려 줘 재사용을 유도
- **사용처·중복**: 모든 대본에서 자료 이름을 세서 안 쓰는 배경·소품을 보여 줌. 같은 프롬프트의 자료는 별칭으로 합쳐 그림 1장을 같이 씀(되돌리기)
- **감정 아이콘 그림**: 아이콘마다 그림을 올려 기본 SVG 대신 씀(`kind:'emote'`, 보관함으로 공유 가능)
