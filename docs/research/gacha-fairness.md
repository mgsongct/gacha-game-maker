# 뽑기 확률·천장·공개 (제안 단계)

모든 생성 게임이 같은 뽑기(계약) 엔진을 씁니다. 지금 규칙과 실제 확률을 계산하고, 표기와 실제가 어긋나는 곳·천장이 사라지는 곳을 정리한 뒤, 확률 공개 관행을 조사했습니다. 건조(영입)의 확률표 공개는 [construction.md](construction.md)에 이미 정리돼 있습니다. 종합 점검은 [maker-review.md](maker-review.md).

## 1. 현황 조사 (빌드 2026.11.03.17)

### 1-2. 실제 확률(계산)

`softRate`를 그대로 옮겨 SSR이 나올 때까지의 분포를 계산했습니다.

| 지표 | 값 |
|---|---|
| SSR 1명까지 기대 뽑기 수 | **24.8회** → 통합 SSR 확률 **4.03%** |
| 10회 안에 SSR | 33.5% |
| 50회 안에 SSR | 87.0% |
| 90회 안에 SSR | 97.5% |
| 112회(소프트 천장 시작)까지 SSR 없음 | 1.03% |
| 150회 천장에 닿을 확률 | 약 0.000003% |

- 기본 확률이 4%로 높아서 **천장·소프트 천장은 사실상 거의 작동하지 않습니다**(100명 중 1명만 112회에 닿음). 천장이 체감되려면 기본 확률을 낮추거나 천장을 당겨야 합니다 — 무엇을 원하는지는 게임마다 다르니 설정으로 남기는 것이 맞습니다.
- 표시하는 4%와 통합 4.03%의 차이는 작지만, 배너 설정(`ssr`·`pity`)을 바꾸면 차이가 커질 수 있습니다.

### 1-3. 문제

## 4. 수치·공식

- 소프트 천장(현재): `p(n) = 4 + (n − 112) × max(2, 96/38) × 0.5` (%), `n > 112`일 때. 150회째 100%.
- 픽업 실제 확률(현재 규칙): `rate + (100 − rate) × k / m` — `m` 같은 등급 후보 수, `k` 그중 픽업 수. `rate=50, k=1, m=2`이면 75%, `k=1, m=4`이면 62.5%.
- 통합 확률 = 1 / 기대 뽑기 수. 기본 4%·천장 150이면 기대 24.8회 → 4.03%. 예) 기본 1%·천장 90으로 바꾸면 소프트 천장(67회부터)이 자주 걸려 기대 53.5회 → **통합 1.87%**(기본의 약 1.9배) — 배너 설정을 바꿀 때 화면에서 바로 계산해 보여 줄 값.

## 5. 확장 아이디어

- 뽑기 기록 화면에 배너별 천장 카운터와 "다음 확정까지" 표시
- 픽업 선택형 배너(여러 후보 중 하나를 골라 확률 업)
