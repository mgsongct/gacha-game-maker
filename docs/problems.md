# 포크 기능 문제 목록 (적용·동작 기준)

기준: 포크 후 추가한 커스텀 기능이 **생성되는 게임에 제대로 적용되고 문제없이 동작하는지**(CLAUDE.md §1). 원안의 생성 경계 — 생성기는 세계관·기본 원칙, 시나리오·콘텐츠는 게임이 구동될 때 실행 중 AI(`liveTick`), 포크 기능 내용도 자동이 기본(사용자는 보고 직접 기입·AI 추가 지시).

위치: 이 목록은 작업 목록이라 `docs/`에 둠(조사 자료는 `docs/research/`).

출처: 도구(`tools/wiring.mjs`·`tools/lifecycle.mjs`·`tools/check.mjs`·`tools/play/qa.mjs`) 결과와, 포크 기능 커밋별 코드 검토(기능 묶음 4개). 줄 번호는 검토 당시 기준이라 바뀌었을 수 있어요.

상태: ✅ 해결(커밋) · 🔧 다음 묶음 · ⏸ 기록만(원안 수치·중요도 낮음) · ❓ 결정 필요
