# 사용자 지시 대장

사용자가 내린 지시·방법·원칙·가이드·「해야 한다」고 한 것을 **원문 그대로** 모으고, 각 지시가 어느 원칙(CLAUDE.md 절)으로 올라가 있고 무엇으로 지켜지는지(도구 점검·시험·절차) 적는 곳입니다(사용자 지시: 「지시와 방법과 원칙, 가이드, 해야한다고 한것들 관리하고 있나?」).

지시는 세 갈래로 나눠 둡니다(사용자 지시: 「정돈시키는 현재 지시와, 앞으로의 개발 방향과 가야할길에 대한 것에 구분이 전혀 없다」).

1. **지금 단계 — 정돈(복구)**: 「현재 하는건 개발이 아니라 개발조차 못할 정도로 처참하게 망쳐놨기에 이를 어떻게든 고치고 있는 과정이다」(사용자). 모듈화 부실과 심각한 구조 위반 때문에 개발 자체를 진행할 수 없어, 그것을 고치는 지시.
2. **정돈 뒤 — 개발 방향·가야 할 길**: 정돈이 끝나야 시작하는 것. 지금은 손대지 않음.
3. **일하는 방법**: 두 단계 모두에 드는 방법·도구 원칙·지시 관리.

- 새 지시는 받는 즉시 해당 갈래에 원문으로 적고, CLAUDE.md의 해당 절에 원칙으로 올립니다. 내 해석·가정은 적지 않습니다(CLAUDE.md 머리).
- 작업을 시작할 때와 단계를 바꿀 때 이 대장과 CLAUDE.md를 확인합니다.
- 「지키는 방법」이 도구가 아닌 것(절차만)은 도구로 옮길 대상입니다 — 「도구화」 칸.
- 어긴 일은 「어긴 기록」에 적고 원인을 고칩니다.
